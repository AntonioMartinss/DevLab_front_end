## 🚀 Sobre o Projeto
O **DevLab** é uma plataforma interativa de jogos desenvolvida como um projeto colaborativo. O foco principal é a experiência do usuário e a integração em tempo real através de **WebSockets**, permitindo partidas multiplayer entre usuários.

## 🛠️ Tecnologias
- **React**: Biblioteca principal para a interface.
- **Tailwind CSS**: Estilização responsiva e moderna.
- **Vite**: Ferramenta de build rápida.
- **React Router DOM**: Gerenciamento de navegação.
- **WebSockets**: Comunicação em tempo real para os jogos (Damas, TicTacDev).

## 📂 Estrutura do Repositório
- `/assets`: Recursos estáticos (imagens, fontes).
- `/components`: Componentes reutilizáveis (Header, Cards, LastPlayed).
- `/data`: Arquivos de configuração e dados dos jogos.
- `/hooks`: Lógica de estado customizada.
- `/pages`: Telas principais (Biblioteca, Jogos).
